# Telegram-бот для продажи звёзд

Бот принимает заказ на 50, 100, 500 или произвольное количество Telegram Stars,
показывает реквизиты и принимает файл чека. После загрузки бот запрашивает
`@username`, отправляет заявку на ручную проверку и не считает фотографию
подтверждением оплаты. После подтверждения чека администратором бот сообщает
покупателю, что звёзды придут в течение 15 минут.

## Что умеет

- выбор готового или произвольного количества звёзд;
- запрос `@username` после получения чека;
- автоматический расчёт суммы;
- приём чека фотографией или PDF;
- ручное подтверждение или отклонение чека администратором;
- автоматическая отправка чека и username владельцу и подключённым менеджерам;
- выдача и отзыв доступа менеджеров через админ-панель;
- изменение цены, реквизитов, лимитов и готовых вариантов прямо в боте;
- хранение заявок и статусов в SQLite;
- уведомление покупателя после обработки заявки;
- команды `/start` и `/cancel`.

## Быстрый запуск на Windows

Нужен Python 3.10 или новее.

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Скопируйте `.env.example` в `.env` и заполните настройки.
3. Откройте PowerShell в папке проекта и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m bot.main
```

Бот работает, пока запущено окно PowerShell. Для постоянной работы разместите
его на VPS или другом круглосуточно включённом сервере.

## Настройки `.env`

- `BOT_TOKEN` — токен от BotFather;
- `OWNER_ID` — числовой Telegram ID владельца;
- `PAYMENT_DETAILS` — реквизиты; перенос строки записывается как `\n`;
- `PRICE_PER_STAR_RUB` — цена одной звезды в рублях;
- `MIN_STARS`, `MAX_STARS` — границы произвольного заказа;
- `DATABASE_PATH` — файл базы заявок.

## Управление менеджерами

Только у владельца из `OWNER_ID` под кнопками выбора звёзд отображается кнопка
**«Админ-панель»**. В ней можно посмотреть список менеджеров, добавить менеджера
по его Telegram ID или удалить его. Там же можно кнопками изменить цену,
реквизиты, минимальное/максимальное количество произвольного заказа и готовые
варианты количества. Настройки сохраняются в SQLite и не сбрасываются после
перезапуска. Остальные пользователи админ-панель не видят и открыть её не могут.

Значения `PAYMENT_DETAILS`, `PRICE_PER_STAR_RUB`, `MIN_STARS` и `MAX_STARS` из
`.env` используются как начальные. После изменения через админ-панель применяются
сохранённые в боте значения.

Важно: каждый подключённый менеджер должен хотя бы один раз открыть бота и
нажать **Start**, иначе Telegram не разрешит боту первым отправить ему заявку.

## Проверка

```powershell
python -m pip install -r requirements-dev.txt
pytest -q
```

Не публикуйте `.env` и токен бота. Бот не проверяет банковский платёж
автоматически — решение по чеку принимает менеджер.
